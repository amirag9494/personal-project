# 📚 Biblioscape

> Your personal digital reading room, combining a minimalist bookstore manager with a cozy Lo-Fi study atmosphere.

---

## 🌟 About The Project

**Biblioscape** is a full-stack portfolio project designed for book lovers and developers who enjoy a calm, focused digital workspace. It bridges a modern Python backend with a classic, sepia-toned vanilla JavaScript frontend, accompanied by an integrated Spotify ambient player to set the mood while you read or code.

---

## 🛠️ Tech Stack

* **Backend:** Python, FastAPI, Pydantic, Uvicorn
* **Frontend:** HTML5, CSS3 (Custom Properties, Dark/Sepia Aesthetic), Vanilla JavaScript (Fetch API)
* **Integration:** Spotify Embed API (Lo-Fi Playlist)
